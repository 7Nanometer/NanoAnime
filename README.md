# NanoAnime番鉴

给中国动漫爱好者用的**追番工具**：看什么、追到第几集、去哪儿看正版。

追新番的人每周都在重复三件事——查今天更新什么、记住自己看到第几集、找个地方接着看。B 站有追番功能，但只覆盖自家版权；Bangumi 数据库很全，但产品体验停留在十年前。这个项目把「追番」单独拆出来做：

- **看什么** —— 首页：焦点位（当季人气代表作轮播）+ 追番周表 + 当季新番；另有「周表」页（完整一周排期）与「最近更新」页（按更新时间排序的全部新番）
- **追到第几集** —— 加入追番、逐集打钩，进度本地保存
- **去哪儿看正版** —— 列出该番的观看渠道，点击跳转到站外

> **本项目不提供任何影视内容。** 不接入片源、不做解析接口、不用 iframe 嵌入任何影视内容。
> 播放动作只有一个：**跳到正版平台**。

## 线上演示

**https://nanoanime.vercel.app/**

> ⚠️ 部署在 Vercel。`*.vercel.app` 域名在中国大陆受 DNS 污染，**国内访问需要代理**——链接本身是好的，不是坏链。

## 功能

### 已完成

| 页面 | 内容 |
|---|---|
| `/` 首页 | **焦点位**（当季人气前 7 轮播：题材标签 + 简介 + 主按钮「去哪看」直达正版跳转）+ **追番周表一行**（今天起 7 天每天挑一部，完整周表在 `/calendar`）+ **热门新番 14 部**（按人气，跳过焦点位那 7 部；全量在 `/updates`）+ **高分合集**（全年代同系列合集按均分排序，评分综合 AniList 与 Bangumi），卡片显示中文名 / 年份 / 评分与下一集播出时刻 |
| `/search` 搜索 | 中、日、英三种写法都能搜，输入防抖 300ms |
| `/anime/[id]` 详情 | 封面、中文名、评分、集数、简介、剧集列表、「哪里能看」、**系列年表**、**制作人员**、**声优** |
| `/person/[id]` 人物 | 头像、名字（日文写法 + 罗马音）、职业标签、英文简介（默认折叠）、**参与作品**（制作 + 配音两个来源合并，人气倒序，可「加载更多」，每行可点回作品页） |
| `/calendar` 周表 | 完整追番周表：周一到周日 7 列（手机竖排），每天更新哪些番、第几集；今天那列高亮 |
| `/updates` 最近更新 | 当季全部新番，按**下一集播出时间**升序（最近要播的排最前，没排期的垫底） |
| `/my` 我的追番 | 追番列表 + 逐集打钩，进度存浏览器本地，刷新不丢 |
| `/login` 账号 | 邮箱 + 密码注册 / 登录 / 退出；登录后服务端可读到当前用户 |

- **考据信息**（详情页）：**系列年表**按年份串出同系列的续作 / 前作 / 剧场版重剪 / 番外，
  超过 12 部折叠；**制作人员**取前 50 条去重后全列（职位名转中文）；**声优**以声优为主体、角色名作附注。
  **人名可点进人物页**，看这个人参与过的作品（制作和配音两个来源都算上）
- 全站顶栏导航，手机窄屏不溢出
- PWA：可添加到手机主屏（图标 + manifest）
- **离线可用**：断网时首页、周表、最近更新、我的追番仍能打开并正常操作（service worker 缓存，纯手写无依赖）
- **云同步**：未登录时记录只存本机（和以前一样，登录不是前提）；登录后与云端**取并集合并**——本地 5 部 + 云端 3 部 = 8 部，同一条以更新时间晚的为准。换设备登录即可拉回。数据靠数据库的行级安全策略隔离，**仅本人可见**。第一次同步前会先向你说明并确认
- 分享到微信 / QQ 有卡片图（og:image 按番剧动态生成）
- 取数失败时显示中文错误页，可点「重试」恢复
- 中文 404 页（Next.js 默认的是英文页）

## 技术栈

- **Next.js 16**（App Router）+ **TypeScript**（`strict`，全项目无 `any`）
- **Tailwind CSS v4** + **shadcn/ui**
- **TanStack Query**
- **Supabase**（Postgres + Auth）—— 账号系统；`@supabase/ssr` 走 cookie，服务端组件可直接读当前用户。
  数据安全靠数据库的**行级安全策略（RLS）**，不是靠藏密钥——`anon key` 本来就公开
- 部署：**Vercel**（不用任何 Vercel 专有服务，保持标准 Next.js Node 形态，便于整体迁移）
- 离线：**手写 service worker**（`public/sw.js`，零依赖）

## 数据来源

| 来源 | 用途 |
|---|---|
| [AniList](https://anilist.co) GraphQL API | 番剧元数据、播出时间表、正版平台外链（免密钥） |
| [Bangumi](https://bgm.tv) | 中文名、中文简介 |

**中文名的来路**：AniList 没有中文字段，中文名只能从 Bangumi 取——用日文原名 + 年份配对，**匹配失败留空，不猜**。配对结果在同步时落成 `data/title-zh.json`，**运行时零外网依赖**：第三方被墙、挂掉、改接口，都不影响产品运行。中文简介与名字同批落盘；Bangumi 上「中文译文 + `[简介原文]` + 日文原文」的混排会拆开只取译文段，整段还是日文原文的会在界面上如实标注。

**高分合集的来路**：评分综合 **AniList 与 Bangumi** 两个来源（只在有分的来源间等权平均，缺分不硬凑；界面副标题如实标注实际用到的来源）。同系列聚合、合集均分与代表作品由离线脚本 `scripts/build-collections.ts` 算好，连同封面与中文名一起落成 `data/collections.json`（Bangumi 原始分在 `data/ratings.json`）——运行时同样零外网依赖，只读文件。

**合规边界**：

- 只做元数据与跳转。不接入任何盗版片源，不做解析接口，不绕过会员验证。
- 海外平台给的是 AniList 的**作品页**外链；国内平台（B 站 / 爱奇艺 / 腾讯视频 / 优酷）**没有「哪部番在哪家」的数据源**，给的是**站内搜索入口**，界面上如实标注了这一点——不包装成「该平台有这部番」。
- 元数据来源在页脚以小字标注。

**已知边界**：

- 中文搜索覆盖 AniList 人气前 2000 部里**配对成功的 1500 余部**（由 `scripts/fetch-title-zh.ts` 一次性从 Bangumi 配对后落盘）。**更冷门的作品、以及 Bangumi 上没有中文名的作品搜不到**——可改用日文原名或英文名。配套的脚本支持 `--scope=season|top2000|all`：`season` 会补齐当季全量（约 100 部、2 分钟），建议每季跑一次；想扩更大范围就重跑 `top2000` / `all`。
- 离线缓存覆盖首页 / 周表 / 最近更新 / 我的追番四个页面。**没访问过、也没预缓存的页面断网打不开**（如番剧详情页）；搜索页断网会显示一个说明页，因为搜索本身就需要联网。

## 本地运行

```bash
git clone https://github.com/7Nanometer/nanoanime.git
cd nanoanime/NanoAnime工程
npm install
npm run dev
```

打开 http://localhost:3000 。

- 需要 **Node.js ≥ 20.9**（Next.js 16 的要求）。
- **AniList 免密钥**，Bangumi 只在一个一次性同步脚本里用到。
- **账号功能需要两个环境变量**：复制 `.env.example` 成 `.env.local`，填入自己的 Supabase
  Project URL 和 publishable key（两者都不是密钥，可以公开）。不配也能跑，
  只是登录页会提示「环境变量没配」。

> ⚠️ **大陆网络注意事项**：直连 AniList、Supabase 都偏慢甚至间歇性超时
> （实测 Supabase 直连 5 次里 3 次超时，走代理 5 次全在 1 秒内）。
> 浏览器会自动走系统代理，但 **Node 进程不会**——本地开发时如果登录页转很久，
> 用这条命令启动开发服务器即可：
>
> ```bash
> HTTPS_PROXY=http://127.0.0.1:7897 NODE_USE_ENV_PROXY=1 npm run dev
> ```
>
> （端口改成你自己代理的那个。这条只在本地开发需要；Vercel 上的服务器在海外，直连很快。）

## 目录结构

文档与代码同一仓库：仓库根目录是文档，代码在 `NanoAnime工程/`。

```
NanoAnime工程/
  app/          页面与路由；app/api/ 是服务端接口（前端不直连第三方 API）
  components/   UI 组件
  lib/          anilist.ts / bangumi.ts / watch.ts / supabase/ —— 第三方数据访问都在这里
  data/         离线数据（中文名与简介），运行时直接读文件
  proxy.ts      会话续期（Next 16 里 middleware 改名叫 proxy，叫旧名字不会被调用）
  public/       sw.js —— 离线缓存的 service worker（不经过打包器的原生 JS）
  supabase/     数据库表结构的唯一出处（建表 + 行级安全策略）
  scripts/      一次性同步脚本
  assets/       字体子集及授权文件
docs/           产品方案 / 项目宪法 / 提示词手册 / 进度
```
