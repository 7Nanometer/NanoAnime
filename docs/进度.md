  - → **正确的验证方式：用浏览器**。本机有 Edge，可以 `--headless --dump-dom` 抓渲染后的 DOM，或用 `--remote-debugging-port` 配 CDP 真的点按钮（Node 24 自带 `WebSocket`，不用装 puppeteer）
- [x] **「重试」按钮已实点验证通过**（无头 Edge + CDP）：点下去 → 重新取数 → 恢复成正常详情页，错误文案消失
- [x] ⚠️ **最需要验的是"两处同时抛错"**：`generateMetadata` 和页面都调 `loadDetail`，**真实断网时两边会同时抛**。这个场景单独验过，中文错误页正常显示（否则你以为加好了，实际线上还是英文 500）
- [x] **`retry()` 而不是 `reset()`**：Next 16 的官方文档明说"多数情况该用 `retry()`"——它会**重新取数**并重渲染，正合"网络问题再试一次可能就好"。`reset()` 只清错误状态、不重新取数
