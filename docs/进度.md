    - 建**两个**账号 A、B（一个账号验不出隔离——只有一个用户时，「只看到自己的行」和「看到所有行」表现完全一样）
    - 权限层：A 登录后 insert / select / update / delete **都通**
    - 隔离层：A 写的记录，B **读 0 行、改 0 行、删 0 行**；A 自己的数据分毫未动
    - ⚠️ **还要补一条「B 能写自己的」**——否则分不清「B 碰不到 A 的」是隔离生效，还是 B 被一刀切禁掉了
    - 更新/删除的「被拒」表现为 **HTTP 200/204 且受影响 0 行**，不是报错（策略是过滤，不是拦截）。所以要看返回的数组长度，不能只看状态码
