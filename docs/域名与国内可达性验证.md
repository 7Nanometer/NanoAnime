# 域名与国内可达性验证 · 操作手册

> 2026-10-03 ｜ 目标：让站点在国内**不挂代理**也能打开
> 现状：`nanoanime.vercel.app` 在国内被 DNS 污染，必须挂代理

> **当前状态（2026-10-03）**：**暂缓执行**。
> 结论已定（必须买自有域名，免费域名全不通），但**执行时机推迟到「第一次需要提前把链接发给别人看之前」**——不是 10-07，也不是 10-08。
> 在那之前它不阻塞任何开发：本地开发、数据源、Vercel 部署都不受影响。**这是分发问题，不是功能问题。**

**先交底**：这一步是**花约 ¥70 买一个必需品**，不是「试探性消费」——**免费域名在国内全部走不通**（见第零节，实测 + 官方文档双重确认）。
它解决的是「域名层」；若 Vercel 的 **IP 段**也被封，还得靠 EdgeOne（腾讯节点）顶上。

## 零、结论：免费域名走不通 —— 必须有自有域名

**这是"实测 + 官方文档"双重确认，不是推测。**

| 方案 | 免费域名 | 中国大陆访问 | 结论 |
|---|---|---|---|
| Vercel | `*.vercel.app` | **打不开**（已实测） | ✗ |
| EdgeOne Pages | `*.edgeone.app` | **必然 401**（官方文档明确，见下） | ✗ |
| Cloudflare Pages | `*.pages.dev` | 不稳（2022 起常被污染） | ✗ |
| Netlify | `*.netlify.app` | 未实测；同为共享域名，**不保证** | ? |

**EdgeOne 官方文档原文**：

> 项目加速区域设置为"**全球可用区（不含中国大陆）**"：非中国大陆网络环境可直接访问，**中国大陆网络环境将返回 401 错误**。
> 项目加速区域设置为"中国大陆可用区"或"全球可用区（含中国大陆）"：须使用系统生成的预览链接访问，该链接**有效期为 3 小时**，超时后将返回 401 错误。

→ **两个区域都走不通**：选"不含大陆"→ 大陆直接 401；选"含大陆"→ 只能用 3 小时过期的预览链接，且未备案的域名根本选不了这个区域。

### 🔑 但同一段话给出了确定的解法

官方原话是「**建议绑定自定义域名以建立稳定访问通道**」，且选"全球可用区（不含中国大陆）"时「**绑定自定义域名不要求工信部备案**」。

**→ EdgeOne + 自有域名 = 大陆可访问 + 免 ICP 备案。**
**→ Vercel + 自有域名 = 同样逻辑（Vercel 官方也把"换自有域名"列为第一条建议）。**

**结论：买域名不是可选项，是必需的。** 两条部署路径都通向同一个前提。

**EdgeOne Pages 免费额度**（平台已跑通，只差域名）：每月 300 万次边缘函数请求、100 万次云函数请求、500 次构建、**流量不限**，自动 HTTPS、Git 推送自动部署。

### EdgeOne Pages 部署步骤（已实测通过，2026-10-03）

控制台 → **创建项目** → **导入 Git 仓库** → 连接 GitHub（授权时选 `nanoanime` 这一个仓库即可）→ 选中 `nanoanime` 仓库。

**构建配置**（唯一需要改的是根目录这一项）：

| 配置项 | 填什么 |
|---|---|
| 框架预设 | **Next**（下拉里就叫这个，即 Next.js） |
| **根目录** | **`./NanoAnime工程`** ← **必须带 `./` 前缀**。填成不带前缀的 `NanoAnime工程` 会直接失败，报 `name error in configuration file` + `No server-handler detected... for pure project`（项目被当成纯静态站，然后"安装依赖失败"） |
| 安装命令 | 保持默认 `npm install` |
| 构建命令 | 保持默认 `npm run build`（即 `next build --webpack`） |
| **输出目录** | **必须确认是 `.next`** —— 若自动填成 `out` 要改掉：`out` 是静态导出的产物目录，而本项目是 SSR（有 `/api` 路由），填错会部署出一堆 404 |
| Node 版本 | 选 **24.x**（本地是 24）；不确定就用默认 22 |
| **环境变量** | **一个都不填** —— 这个项目运行时不需要任何密钥 |

点部署，等 2–4 分钟，得到 `https://<随机串>.edgeone.app`。

**然后立刻测**：手机流量 + 关掉所有代理，打开这个链接。

> 若构建失败，把 Build Log 的报错原文贴给 Claude Code，**让它先分析、不要自己改依赖版本或改名**。

### B · 兜底：不依赖网络（无论如何都该做）

- **演示录屏**：面试时边放边讲，**比丢一个链接更好用**——你能控制节奏、只展示要突出的部分
- **本机跑 + 共享屏幕**：线上笔试/面试时共享屏幕跑本地版，**体验比公网链接更流畅**（没有跨境延迟）

这条不受任何封锁影响，而且**面试场景下往往比链接更有效**。

### 附：如果是想买域名但卡在 Veriff

**换注册商，不要死磕 Veriff。** Porkbun 从 2026-04 起对部分新账号强制 Veriff 身份验证（按地区 / IP 风控标记，中国大陆 IP 容易命中）；且 Veriff 本身是境外服务，国内访问它可能就不通——不挂代理连不上、挂了代理又可能被判高风险。

可选：**Namecheap / Namesilo / Spaceship / Dynadot**（都支持支付宝的说法不一，需实测）。
⚠️ 但整个行业在收紧，换一家也可能要求验证。**而且即使买到域名，若 Vercel 的 IP 段被封，照样不通** —— 所以第零节 A 那条路无论如何都要考虑。

## 二、先想好名字（不要边买边想）

候选方向：

- `nanoanime.app` / `nanoanime.dev` —— Google 的后缀，适合应用类，**强制 HTTPS**，Vercel 自动签好证书
- `nanoanime.com` —— 最通用，但动漫相关域名抢手，**大概率被占**
- `fanjian.app` —— 「番鉴」拼音
- 加数字：`7nanoanime.com` / `nanoanime7.com`

**不要买 `.cn`**：实名要求一样要走，且后续若要迁国内反而多一层约束。

查可用性：Porkbun 首页搜索框直接输入就显示，不用注册也能查。

**只买 1 年**。首年便宜、续费贵，等确认这条路走得通再续多年。

## 三、买（约 10 分钟）

## 四、在 Vercel 绑定域名（约 5 分钟）

1. 打开 `vercel.com` → 进入 `nanoanime` 项目
2. 顶部 **Settings** → 左侧 **Domains**
3. 输入你的域名 → **Add**
4. **看它弹出来的域名卡片，把上面的 DNS 值抄下来**

卡片上通常给两行：

```
A      @      → 76.76.21.21        （新项目可能显示 216.198.79.1 之类的别的值）
CNAME  www    → cname.vercel-dns.com（也可能是项目专属的一串）
```

> ⚠️ **必须以卡片上显示的值为准，不要照抄任何教程（包括这一份）**。
> Vercel 会逐一比对你配的记录，抄错了域名会一直卡在 `Invalid Configuration`。
> 它若另外要求加一条 `TXT` 记录，照着加就行。

---

## 五、在 Porkbun 配置解析（约 5 分钟）

1. `porkbun.com` → 右上 **Domain Management** → 点你的域名 → 切到 **DNS Records**
2. **先删掉 Porkbun 自带的默认记录**（残留的 A / CNAME 会干扰验证）
3. 加第一条：
   - Type：`A`
   - Host：**留空**（留空 = 根域，即 `nanoanime.app` 本身）
   - Answer：抄 Vercel 卡片上的 IP
4. 加第二条：
   - Type：`CNAME`
   - Host：`www`
   - Answer：抄 Vercel 卡片上的 CNAME 值
5. 保存

> 根域填法若有疑问，以 **Vercel 卡片给的提示**为准（Porkbun 是留空，别的服务商可能是 `@`）。

---

## 六、等接通（10 分钟 ~ 几小时）

回到 Vercel 的 **Settings → Domains** 刷新：

- 域名卡片从 `Invalid Configuration` → **两个绿色勾** = 通了
- HTTPS 证书 Vercel 自动签发（几分钟），不用管

## 七、验证国内可达性 ← 这才是真正的目的

### 🔴 铁律：测的时候必须彻底关掉代理

不关，测出来的是「**代理能通**」，不是「**国内能通**」——结论直接作废。

**手机上（最真实，优先用这个）**
1. **关 WiFi**，用流量
2. **关掉 VPN / 加速器 App** —— Clash、Shadowrocket、小火箭、各种机场客户端，**这一步最容易漏**
3. 浏览器打开 `https://你的域名`

**电脑上**
- 关系统代理、关浏览器代理插件、退掉软路由 / 机场

### 再加一道：多节点测

打开 `itdog.cn` → 找「**网站测速**」→ 输入域名 → 开始
它会从国内各省市的电信 / 联通 / 移动节点去请求。

> ⚠️ **不要只用 ping 测**。解析正常、但 HTTPS 握手中途被掐（SNI 阻断）时，**ping 照样通、页面照样打不开**。
> 要看的是**「HTTP 请求是否成功」**。

### 结果判读

| 结果 | 含义 | 下一步 |
|---|---|---|
| 手机流量 + itdog 多节点**都通** | 换域名解决了 | ✅ 收工，见第九节 |
| 部分通、部分不通 | 不稳定 | 走第八节第 1 步（Cloudflare） |
| **完全不通** | 被封的是 Vercel 的 **IP 段**，不是域名 | 只能迁国内 + 备案 |

## 八、如果不通 —— 阶梯式，一次只改一个变量

1. **把 DNS 托管换到 Cloudflare**（免费）
   - 顺序：**先灰云验证通过，再切橙云** —— 橙云会干扰 Vercel 的域名验证
   - 同时 Cloudflare 提供代理中转，可能绕开直连问题
   - ⚠️ Cloudflare 免费版在国内本身也不稳，只是「可能更好」，不是保证

2. **第三方优选 CNAME**（圈内常用，如 `vercel-cname.xingpingcn.top`）
   - ⚠️ 是**第三方服务，随时可能停**；且若其节点在国内，有备案相关问题
   - 只当临时方案，不要写进简历/README

3. **迁国内服务器 + ICP 备案**（7–20 个工作日）—— 唯一的确定解，但**赶不上 10-07**
