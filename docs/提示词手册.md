# Claude Code 提示词手册 · NanoAnime番鉴

> 配套：`项目宪法.md`（要转成根目录 CLAUDE.md）、`产品方案.md`、`进度.md`
> 用法：找到对应阶段，整段复制到 Claude Code。

## 三条铁律

**说结果，不说步骤**
```
❌ 打开 app/page.tsx，在第 23 行加一个 fetch……
✅ 首页显示 20 部本季新番封面墙。数据用 AniList。
```

**报错贴全文**
文件名 + 行号 + 错误信息，一个字不改。总结一次，多绕一圈。

**每条都要验收标准**
缺了它就会一直问"这样可以吗"。

## 三个操作

| 操作 | 输入 | 何时用 |
|---|---|---|
| 计划模式 | `Shift+Tab` ×2 | 改 3 个以上文件前 |
| 清空上下文 | `/clear` | 换任务时 |
| 查记忆 | `/memory` | 想加规则时 |

## 一、启动

在 VSCode 里打开文件夹 `E:/Vibe Coding/NanoAnime`，启动 Claude Code。

输入 `/context`，确认列表里出现 `CLAUDE.md`。

顺手建一个收工命令（在 Claude Code 里说，建完以后 `checkpoint` 就能用）：
```
创建 .claude/commands/checkpoint.md，frontmatter 只写 description: 收工检查。
正文四条：
1. 确认本地能正常启动，不能就先修
2. 提交代码，commit message 用中文
3. 更新 docs/进度.md：勾掉已完成项、记录问题、写清下次从哪继续
4. 三句话总结今天做了什么
```

## 二、第一步：建立 CLAUDE.md

```
把 docs/项目宪法.md 里「分割线之后」的全部内容，原样写入项目根目录的 CLAUDE.md。

然后读 CLAUDE.md、docs/产品方案.md、docs/进度.md，用五句话回答：
1. 项目要做什么
2. 技术栈
3. 你的红线
4. 现在从哪开始
5. 方案里哪里不清楚、需要我补充

先不要写代码。
```

第 3 条答不出来 = 红线没生效，停下检查。

## 三、M0 · 骨架跑通（09-29 ~ 10-01）

**初始化**
```
在 E:/Vibe Coding/NanoAnime/NanoAnime工程 下初始化 Next.js（App Router + TypeScript + Tailwind）+ shadcn/ui + TanStack Query。
应用名统一为 **NanoAnime番鉴**（package.json 的 name 用 nanoanime），并把 CLAUDE.md 里的项目名改成它。

同时在 E:/Vibe Coding/NanoAnime 根目录初始化 git：覆盖整个项目（含 docs 和 CLAUDE.md），
.gitignore 排除 node_modules/ .next/ .env* .workbuddy/，做首次提交；把版本控制约定补进 CLAUDE.md。

不写业务代码。
做完给我：怎么在本地打开页面 + 目录结构。
```

**打通 AniList**
```
打通 AniList（https://graphql.anilist.co，无需 key）。
取本季新番：封面、日文原名、英文名、总集数、播出星期、评分、AniList id。
（AniList 没有中文字段，中文名 M1 接 Bangumi 再补）
封装进 lib/anilist.ts，缓存 ≥1 小时。封面白名单：next.config 放行 s4.anilist.co。

先给我 GraphQL 查询语句，确认后再写代码。
做完按 /checkpoint 收工，把 M0-1、M0-2 在 docs/进度.md 打钩。
```

**首页**
```
做首页：响应式网格，每格 = 封面 + 日文原名 + 英文名 + 更新状态，数据用 GET /api/anime/season。

两条兜底必须做：
1. 没有英文名时退回日文原名（本季 20 部里有 3 部）
2. 未开播作品没有评分、多数没有总集数 —— 缺字段要优雅降级，不能渲染出 null 或空白

样式能看清就行。
验收：本地打开能看到 20 部本季新番封面墙，封面正常显示，无 null/空白，手机上正常。

图片加载慢或失败，先告诉我原因，不要自行加兜底逻辑。
```

**修首页图片**
```
开发环境关掉 Next 图片优化：next.config 设 images.unoptimized: process.env.NODE_ENV === 'development'，
让本地浏览器直连图床，绕开 7 秒超时。生产环境保留优化不动。

验收：本地刷新首页，20 张封面全部显示（允许慢，不允许 500）。

做完在 docs/进度.md 追加：图片慢的根因是 AniList 图床国内直连慢 + Next 优化器 7 秒硬超时；
M1 接 Bangumi 后改用 lain.bgm.tv 图床解决。
```

**收工**
```
确认本地能正常启动；提交代码（commit 用中文）；更新 docs/进度.md。
```

## 四、M1 · 番剧库（10-02 ~ 10-04）

**接 Bangumi 取中文名（离线批量）**
```
写一个一次性脚本（放 scripts/），用 AniList 的 title.native + 首播年份搜 Bangumi，
把中文名落成 data/title-zh.json（结构：anilist_id → { bangumi_id, title_zh }）。

四条约束：
1. 匹配失败留空，不要猜
2. 结果写进文件并提交 git —— 应用运行时直接读文件
3. 不要在页面或任何接口里实时请求 Bangumi
4. 图床不动，继续用 AniList

注意：Bangumi 国内被墙，跑这个脚本时需要挂代理。

验收：首页卡片显示中文名；抽查 10 部，配对正确 ≥ 8 部。
```

**详情页**
```
做 /anime/[id]，从首页点击进入。
内容：大封面 + 中文名（没有则显示日文原名）+ 日文原名 + 评分 /
简介（description 带 HTML，清掉）/ 制作公司 + 播出时间 + 总集数 + 状态 /
剧集列表（集数、标题、播出日期）/「哪里能看」占位区。

中文名读本地 data/title-zh.json，不要实时请求 Bangumi。
简介先用 AniList 的英文，清掉 HTML 后原样显示（中文简介等 M3 接 TMDB 时替换）。
剧集数据若现有接口没返回，扩展 AniList 查询，不要另找数据源。

验收：从首页点任意一部进详情页，信息完整，剧集列表正常。
```

**错误页**
```
给详情页加一个中文错误页：取数失败（网络超时等）时显示中文提示 + 重试按钮。
（Next 默认的英文 500 页不能用；国内访问海外数据源会时不时撞上超时）
```

**搜索**
```
做 /search：输入关键词 → 匹配番剧（封面 + 名字 + 年份）→ 点击进详情页。

搜索合并两个源再去重：
① 本地 data/title-zh.json 的中文名
② AniList 搜索接口（日文 / 英文 / 罗马音）

请求走服务端代理，加防抖。AniList 的 pageInfo.total 不可信（实测恒返回 5000），翻页不要依赖它。

验收：搜「Frieren」/「薬屋」/「药屋」三者都能命中。
```

## 六、M3 · 上线（10-07，硬节点）

**哪里能看**
```
详情页「哪里能看」：列出番剧所在正版平台（B站/爱奇艺/腾讯/Netflix/Crunchyroll），
点击新标签页打开。数据用 AniList externalLinks，其次 TMDB watch providers。

⚠️ 只做跳转链接。不嵌播放器、不解析播放地址、不用 iframe。拿不到就显示「暂无正版渠道」。
验收：随便一部番都能看到可点击的正版链接，点了能跳。
```

**PWA + 部署**

## 七、通用

**报错**
```
报错了，完整输出：
（贴原文，不删减）
先讲原因，再给方案。不要一次改很多文件。
```

**自查**
```
检查刚才的改动，只报告不修改：
1. 是否违反红线（播放 / 盗版源 / 解析地址）
2. 是否前端直连第三方 API
3. 是否硬编码密钥
4. 是否用了 any
5. 是否有多余代码
```

**改太多**
```
停，改动太多了。
回到上一个能跑的状态，只做一件事：____
```

**开工**
```
先读 docs/进度.md，告诉我：上次做到哪、今天下一步是什么、有无遗留问题。
等我确认再动手。
```

## 八、卡住时

| 症状 | 对策 |
|---|---|
| 越改越乱 | `/clear` 重开，重说需求（CLAUDE.md 会自动加载） |
| 同一个错改三遍 | 贴全文 + 「先只解释原因，不要写代码」 |
| 不守约定 | `/memory` 把具体规则加进 CLAUDE.md（"2 空格缩进"优于"注意格式"） |
| 一直问你 A 还是 B | 缺验收标准，补「做完我要能……」 |
| 想装一堆依赖 | 「不新增依赖，用现有的做到能跑」 |
| 越来越慢 | 对话太长，`/clear` 后先让它读 `docs/进度.md` |

跑偏时不要重述需求，**只指出错在哪**：
```
❌（从头再讲一遍）
✅ 这改动了公共接口，保持签名不变，只改内部实现。
```
