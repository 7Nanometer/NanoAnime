---
description: 收工检查
---

1. 确认本地能正常启动，不能就先修
2. 更新 docs/进度.md：勾掉已完成项、记录问题、写清下次从哪继续
3. 提交：**代码 + `docs/` 一起提交**，commit message 用中文
   - `docs/` 里的改动**不由我写**（那是文档助手小七改的），但**必须由我 commit**——收工时不许把 `docs/` 的改动留在工作区
   - 所以 `git add` 要显式带上 `docs/`，提交完 `git status` 必须是干净的
   - 提交信息里**注明本次包含文档更新**（写清是哪些文档、改了什么）
4. 三句话总结今天做了什么
